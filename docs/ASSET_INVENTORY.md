## Asset requirements for the redesigned portfolio

1. Use real project screenshots where possible.
2. For AirCanvas, prefer a photo/screenshot of the Android drawing UI and the physical ESP32 + OLED output; do not use a projector image.
3. For PocketPilot, capture the dashboard, sign-in screen, analytics, and offline/cloud-sync state without exposing personal financial data or credentials.
4. For hardware projects, use actual build photographs or clear technical diagrams.
5. Provide meaningful alt text and optimised image formats.
6. Do not fabricate screenshots or imply an unbuilt feature exists.
7. Keep original project repositories untouched when preparing portfolio-specific copies or generated assets.
